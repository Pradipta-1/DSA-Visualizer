About this project

DSA Visualizer turns algorithm execution into something you can watch, pause, rewind, and question. Every algorithm is implemented as a pure step generator — it never touches the screen directly. A single animation engine consumes those steps to drive the canvas, the code highlight, and the explanation panel in lockstep, which is what makes the code ↔ visualization link exact rather than approximate.

Frontend

HTML / CSS / vanilla JS in this build (designed to map directly onto a React + TypeScript + Vite + Tailwind stack).

Animation

CSS transitions + a structured step queue — swappable for Framer Motion / D3 without touching algorithm logic.

Architecture

AlgorithmEngine → StepManager → AnimationController → ExplanationEngine, each independently testable.
